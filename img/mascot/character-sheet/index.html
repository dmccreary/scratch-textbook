    Character Sheet: Scratch the Cat¶

    The canonical identity document for Scratch the Cat, the pedagogical mascot for the Scratch Programming for Kids textbook. Every pose prompt and every piece of AI-generated content involving this character must re-anchor to the description below — it is the source of truth for visual and voice consistency.

    A note on originality. This character sheet describes an original illustration created for this textbook, drawn in the spirit of the friendly orange cat every learner meets the moment they open the Scratch editor at scratch.mit.edu. It intentionally echoes that instantly recognizable silhouette and color so the book feels like a natural companion to the tool — but the artwork generated from these prompts is new, not a trace or reproduction of MIT/Scratch Team's copyrighted sprite assets. "Scratch," the Scratch logo, and the Scratch Cat sprite are trademarks/copyrighted works of the Scratch Team and MIT. This textbook is an independent, non-commercial educational project (see license.md, CC BY-NC-SA 4.0) and is not affiliated with or endorsed by MIT or the Scratch Team. Do not use these generated images to imply official Scratch branding or endorsement.

    Identity¶

    • Name: Scratch the Cat
    • Species: Cat
    • Subject: Scratch visual block-based programming for kids ages 8–12
    • Catchphrase: "Let's build something purr-fect!"

    Visual Description¶

    • Body color: Warm tangerine orange — hex #FF8C1A
    • Accent color: Cream / light peach (belly, inner ears, paws, muzzle) — hex #FFE0B2
    • Clothing / accessories: None — kept deliberately simple and unadorned, like the classic sprite it's inspired by, so the character reads instantly at small sizes
    • Expression: Big round curious eyes with dark pupils, small triangular ears, soft whisker lines, warm closed-mouth smile by default
    • Size proportion: Small-to-medium, chibi-style proportions with a slightly oversized head relative to the body — friendly and approachable for young readers
    • Art style: Flat 2D cartoon/vector illustration, bold clean black outlines, bright saturated flat colors, no gradients or textures

    Personality¶

    • Playful and curious — always eager to try the next block
    • Patient and encouraging — treats every bug as a clue, not a failure
    • Inventive — loves remixing ideas into something new
    • Warm and approachable — never condescending, always rooting for the learner

    Voice¶

    • Uses simple, upbeat language a 3rd-grade reader can follow independently
    • Leans on gentle cat/coding puns ("paw-some," "let's scratch that itch to code")
    • Refers to learners as "coders" or "creators," never "students" in-character
    • Signature phrases: "Let's build something purr-fect!", "Every bug is just a clue!", "Click, drag, and see what happens!"

    Why This Mascot¶

    Scratch the Cat is the same friendly orange cat every learner already meets the instant they open the Scratch editor, so reusing that familiar face turns the textbook mascot into a bridge between the book and the tool — one less new thing for a young reader to learn. The simple, unaccessorized flat-cartoon style mirrors Scratch's own iconic sprite art, and the orange/cream palette was chosen to match both the cat's natural coloring and this book's existing orange / deep-orange MkDocs Material theme, so the mascot feels woven into the book rather than pasted on top of it.
