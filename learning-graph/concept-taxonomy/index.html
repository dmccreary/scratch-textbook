    Concept Taxonomy¶

    Taxonomy categories for organizing Scratch Programming for Kids learning graph concepts.

    TaxonomyID Category Name Description
    FOUND Foundation Concepts Core Scratch interface and visual programming fundamentals (21 concepts)
    SCRATCH_ACC Scratch Account & Community Account creation, community participation, and project sharing (14 concepts)
    MOTION Motion & Coordinates Sprite movement, positioning, and stage coordinate system (14 concepts)
    LOOKS Looks & Animation Visual appearance, costumes, speech bubbles, and animation (10 concepts)
    SOUND Sound & Music Audio playback, tempo, sound effects, and synchronization (7 concepts)
    PEN Pen & Drawing Pen extension for drawing trails, geometric patterns, and visual art (12 concepts)
    CONTROL Control Structures Loops, conditionals, and program flow control (22 concepts)
    EVENTS Events & Broadcasting Event-driven programming, sprite communication, and broadcasting (19 concepts)
    SENSING Sensing & Input Sensors for interaction, collision detection, and input handling (10 concepts)
    OPERATORS Operators & Logic Mathematical, comparison, and Boolean operators (14 concepts)
    DATA Variables & Lists Data storage with variables and lists, scope, and game state management (23 concepts)
    CLONING Cloning Creating and managing multiple dynamic sprite instances (6 concepts)
    EXTENSIONS Extensions & Hardware Scratch extensions for multimedia, translation, and physical computing (11 concepts)
    CUSTOM_BLOCKS Custom Blocks & Abstraction Defining reusable procedures with parameters (6 concepts)
    DESIGN Design Process Software design methodology, planning, and iterative development (23 concepts)
    DEBUGGING Debugging & Testing Error detection, debugging strategies, and quality assurance (7 concepts)
    BLOCK_TYPES Block Types & Shapes Understanding Scratch block categories, shapes, and color coding (14 concepts)
