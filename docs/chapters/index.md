# Chapters

This textbook is organized into 11 chapters covering 226 concepts.

## Chapter Overview

1. [Welcome to Scratch](01-welcome-to-scratch/index.md) - Introduces the Scratch interface, visual programming basics, and community features.
2. [Sprites, Stage, and the Coordinate System](02-sprites-stage-coordinates/index.md) - Covers sprites, the stage, coordinate system fundamentals, and motion block basics.
3. [Motion Blocks and Block Categories](03-motion-blocks-categories/index.md) - Explores motion blocks in depth, block categories, shapes, colors, and the blocks palette organization.
4. [Events, Sequences, and First Scripts](04-events-sequences-first-scripts/index.md) - Teaches event-driven programming with the Green Flag, sequential execution, and basic control structures.
5. [Sounds, Extensions, and Sharing Projects](05-sounds-extensions-sharing/index.md) - Explores sound blocks, Scratch extensions, project sharing, and versioning basics.
6. [Broadcasting, Conditionals, and Sensing](06-broadcasting-conditionals-sensing/index.md) - Introduces sprite communication via broadcasts, if/else conditionals, and sensor-based interactions.
7. [Variables, Lists, and Data Management](07-variables-lists-data/index.md) - Covers variables for game state, lists for collections, and variable scope concepts.
8. [Animation, Parallelism, and Debugging](08-animation-parallelism-debugging/index.md) - Teaches costume animation, parallel execution, loops, and systematic debugging techniques.
9. [Advanced Control and Operators](09-advanced-control-operators/index.md) - Explores complex loops, Boolean logic, clone management, and physical computing extensions.
10. [Game Mechanics and Win/Lose Conditions](10-game-mechanics-win-lose/index.md) - Builds complete game mechanics with collision detection, scoring, lives, and win/lose states.
11. [Design Process and Capstone Project](11-design-process-capstone/index.md) - Guides students through the complete design cycle: imagine, plan, create, test, improve, share, and reflect.

## How to Use This Textbook

Read chapters in order — concepts are introduced in dependency order so prerequisites are always covered before they are used. Each chapter lists the concepts it covers and which previous chapters to review.

---

**Note:** Each chapter includes a list of concepts covered. Make sure to complete prerequisites before moving to advanced chapters.
